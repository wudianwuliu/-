# 网申自动填表工具（jobfill）

网申填表真正烦人的不是"填"，是**同一套信息填一百遍**：每家公司问的字段几乎一样，
只是叫法不同——"毕业院校" / "学校名称" / "院校全称"，背后都是同一个值。
这个工具把这件事变成：**资料填一次 → 接管你已登录的 Chrome → 一键填 → 人工核对 → 手动提交**。

优先适配**北森**（`*.zhiye.com`，多数银行/央国企/大厂校招在用），其余系统靠统一
的标签识别兜底。

---

## 一、安全边界（先说这个，因为填错比不填更麻烦）

| 约束 | 具体做法 |
|---|---|
| **绝不自动提交** | 代码里不存在任何点击「提交/保存/投递/下一步/删除」的路径。填完就停，截图留证，等你自己点。 |
| **绝不误填敏感字段** | 「家庭主要成员」「紧急联系人」区块默认整块跳过；验证码、密码类标签直接忽略（`ignore_labels`）。「姓名」有排除词，不会填进「父亲姓名」。 |
| **宁可空着不编造** | `profile.yaml` 里是 `null` 的字段（身份证号、出生日期…）保持空白，并在 `check` 里提醒你补。工具不会猜。 |
| **登录/验证码/滑块永远人工** | 接管的是你自己登录好的浏览器，工具只在页面上填值。 |
| **重复块添加有白名单** | 只点文本以「添加/新增」开头、且**区块能对上**的按钮，否则宁可不点。 |

## 二、快速开始

```powershell
cd D:\deepseek\rw\formfiller

# 1) 起一个可接管的 Chrome（独立配置目录，登录一次长期有效）
.\launch_chrome.ps1

# 2) 在弹出的 Chrome 里登录网申系统，把「填写简历」页面停在当前标签页

# 3) 体检：看看个人资料还缺什么
.\jobfill.cmd check

# 4) 填表（--learn：遇到没认出来的字段会问你，并记住答案）
.\jobfill.cmd fill --learn

# 5) 人工核对 → 自己点提交
```

> `jobfill.cmd` 只是帮你设好 `PYTHONPATH` 再调 `py -3 -m jobfill`。
> 想直接写完整命令就用：`py -3 -m jobfill fill --learn`
> （前提是依赖可导入，见第七节）

## 三、命令速查

| 命令 | 作用 |
|---|---|
| `check` | 资料体检：列出 `profile.yaml` 里还没填的字段、识别表覆盖情况、端口状态 |
| `scan --url <地址>` | **只看不填**：把页面上所有控件、区块、候选标签列出来（排查用，可 `--out scan.json`） |
| `fill --dry-run` | **只匹配不填**：预览「哪个框会填什么值、来自哪条数据」。不修改页面。 |
| `fill --learn` | 正式填 + 对未识别字段逐个人工确认，答案写进 `learned.yaml`（以后所有公司复用） |
| `fill -y` | 非交互，未识别字段直接跳过（适合放进脚本） |
| `fill --only 教育` | 只填区块/标签里含这个词的字段（分步表单很有用） |
| `fill --resume-file a.pdf --photo-file b.jpg` | 顺便上传简历附件 / 证件照 |
| `fill --no-add-blocks` | 不自动点「添加」补足教育/实习/项目经历 |
| `learned` / `learned --forget "身高(cm)"` | 查看 / 删除已记住的字段 |
| `launch-info` | 怎么启动带调试端口的 Chrome，以及当前端口状态 |

常用参数：`--adapter beisen|generic`、`--port 9222`、`--match-url 片段`、`--new-tab`、
`--profile <路径>`。

## 五、他是怎么认出字段的

匹配分 = 标签相似度 + 区块吻合(+0.12) + 控件形态相符 + 重复块序号吻合(+0.05)，
按分数从高到低**全局贪心分配**，阈值 0.55。

**标签相似度**（`normalize.py`）
1. 归一化：全角转半角、去掉 `*`、`（必填）`、`请输入`、空格、各种标点 → 再比较
2. 完全相等 = 1.00
3. 互相包含 = 0.84 ~ 0.98（按覆盖比例，覆盖太少直接不算）
4. 编辑距离 ≥ 0.75 = 0.50 ~ 0.85
5. **否定词保护**：「同意」不会匹配到「不同意」，「全日制」不会匹配到「非全日制」

**选项匹配**（单选/下拉/多选）
- profile 里的值 → 用 `value_synonyms` 展开成同义写法（`本科` → `大学本科/全日制本科/学士`；`是` → `有/同意/接受`）
- 再跟表单选项逐个比对，**匹配不上就报「需手动」并列出可选项**，绝不瞎选

**几个真实踩过的坑，都在代码里做了处理**
- 表格布局：标签在**前一个单元格**（`<td>姓名</td><td><input></td>`）
- 标签候选要多个：`label[for]`／包裹式 `label`／`placeholder`／前置 div／容器文本，取最匹配的那个
- **容器文本不能乱用**：一行塞了两个控件的容器文本（"身份证号 政治面貌"）绝不当标签，
  否则「身份证号」会被填成「共青团员」
- 区块要取**最后一个**排在元素之前的标题：取第一个会把页面 `h1`（网站名）当区块名，
  「家庭主要成员」的判定就全废了
- 重复块序号三层判断：`name/id` 里的数字（`eduSchool0`→0，最可靠）→ 结构分析
  （取重复次数最少的兄弟容器：记录容器重复"记录条数"次，`tr` 重复"行数"次）→ 0
- **同一字段可填多个控件**（手机号 + 确认手机号、省市区三级联动），但第二次起要求强匹配

## 六、支持的控件形态

| 形态 | 做法 |
|---|---|
| 文本框 / 文本域 | `fill()`，失败则改 `value` 并派发 `input/change/blur`（jQuery 系校验读的就是 `.val()`） |
| 原生 `select` / 多选 | 填值时**现场重读选项**（省市区这种级联下拉的选项是动态加载的） |
| 单选 / 多选组 | 按选项文本匹配后点击那个 option，回读确认 |
| 假下拉（div 模拟的 select） | 点开 → 在弹出面板里按文本精确选 → 点中 |
| 日期 | 原生 date 输入框直接填；只读框 + 自定义日历则点开面板点年、点月，**点出值来就不覆盖**；最后才兜底改 value |
| 文件上传 | `set_input_files`（对隐藏 input 也有效），文件不存在就报「需手动」 |
| 验证码 / 密码 | 一律跳过 |

每种控件填完都会**回读校验**，值没落上去会重试一次，报告里逐项显示 `✔ / ! 需手动 / × 失败`。

## 七、环境说明

依赖是 `playwright` + `PyYAML`。**在当前这台机器上**，系统 Python 的 site-packages
不可写（沙箱限制），所以依赖装在工作区内的 `libs/` 里，靠 `PYTHONPATH` 加载——
`jobfill.cmd` 已经帮你设好了。

如果你换一台机器，或者想在普通终端里跑：

```powershell
py -3 -m pip install -r requirements.txt     # 或 pip install playwright pyyaml
py -3 -m jobfill check                        # 装到全局就不用设 PYTHONPATH 了
```

浏览器**不需要额外下载**：Playwright 用 `channel="chrome"` 直接调你已装的 Chrome。

## 八、已知限制（先知道，少踩坑）

1. **扁平表格里的重复块**：如果多家经历挤在同一个 `<table>` 里（每段占几行，没有
   独立的记录容器，`name` 里也没有序号），工具无法区分"这是第几段"，只会填第一段。
   遇到就 `--only` 一截截填，或用 `--learn` 手动补。
2. **高度定制的组件**：富文本编辑器、带搜索的联想输入、树形选择，工具填不了，会列进
   「未匹配控件」由你手动处理。
3. **分步表单**：一次只处理当前页面，北森那种「下一步」式表单需要每步跑一次
   （这正是 `--only` 的用武之地）。
4. **惰性加载**：工具会先整页滚动一遍触发渲染，但如果某个区块必须手动展开（"展开更多"），
   请先自己点开再跑。
5. **不注册、不改密码**：`profile.yaml` 里的 `misc.password` 只是给你自己记的，工具不会用。

## 九、出问题怎么查（推荐顺序）

```powershell
# 1) 先看匹配，不动页面
.\jobfill.cmd fill --dry-run

# 2) 还是不对，看页面上到底有什么控件（含每个控件的候选标签）
.\jobfill.cmd scan --out scan.json

# 3) 看报告 JSON 和截图：reports/fill_<时间>.json / .png
#    每条 outcome 都有 source（profile:路径 / learned:标签 / open:题目id）

# 4) 单个字段老是认不出：在 field_map.yaml 对应字段的 aliases 里加一条
#    （最省事的办法还是 fill --learn，让它自己记住）
```

## 十、测试

```powershell
# 纯逻辑单测（不需要浏览器）——50 项
py -3 tests\test_matcher.py

# CLI 接线测试（不需要浏览器）——24 项
py -3 tests\test_cli.py

# 端到端：启动本地模拟网申页 + 真 Chrome，跑完整流程并逐项断言 —— 64 项
py -3 tests\test_e2e.py
```

端到端验证覆盖的关键点：iframe 表单能扫到、提示弹窗能关掉、表格布局标签能认出、
单选/下拉/假下拉/只读日历/文本域都能填上、重复块能自动补足、
**家庭信息与验证码绝不被填**、`profile` 里 `null` 的字段保持空白、
**提交/保存按钮点击次数必须为 0**。
